# Pr# 🎮 Diário de Sobrevivência — Blog Co-op

Um blog focado em análises, experiências e dicas sobre jogos cooperativos e de sobrevivência, incluindo títulos como *Dead by Daylight*, *It Takes Two*, *Don't Starve Together* e *Overcooked*.

---

## 🚀 Tecnologias Utilizadas

- **HTML5** (Estruturação semântica)
- **CSS3** (Estilização responsiva e efeitos visuais)
- **Node.js & lite-server** (Servidor de desenvolvimento)

---

## 💻 Como Executar o Projeto

Você pode executar o projeto de duas formas: no seu computador ou direto pelo GitHub Codespaces.
